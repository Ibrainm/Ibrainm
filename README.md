### ¡Hola! Soy Ibrainm 👋

Desarrollador Full Stack centrado en la construcción de aplicaciones web escalables, diseño de bases de datos relacionales y desarrollo de APIs RESTful. 

Trabajo enfocándome en código limpio, resolución eficiente de problemas y entregas funcionales.

#### 📌 Estado actual
- 🔭 Desarrollo de APIs y aplicaciones web fullstack con el ecosistema Laravel y Next.js.
- 🌱 Profundizando en arquitectura backend avanzada y optimización de datos.
- 💬 Abierto a colaborar en proyectos Full Stack (Laravel, React/Next.js).

#### 🚀 Áreas de enfoque
- **Backend:** Diseño de APIs RESTful con Laravel, modelado y optimización en PostgreSQL, arquitectura modular y testing con PHPUnit/Pest.
- **Frontend:** Interfaces dinámicas e interactivas con React, Next.js y TypeScript, estilizadas con Tailwind CSS.
